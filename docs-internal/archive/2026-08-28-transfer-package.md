## What the project is

Titrate is a personal fork of **GLPal**, an abandoned open-source GLP-1 dose/weight tracking PWA (React 19 + Dexie/IndexedDB). The upstream GitHub repo was gone (404) when work started, so the fork was built by reverse-engineering the **deployed minified production bundle** and applying a chain of **deterministic, SHA-gated Python patch scripts** to it. There is no React source tree. All work is surgical edits to one minified JS file, reproduced byte-for-byte by the build.

Non-negotiable requirements (from Marc): PWA, no account/sign-up, all health data local on device (IndexedDB), no cloud dependency, works offline, dose records editable and deletable, simple workflow like GLPal.

# 03 — Algorithms

## 1. Medication level model (`v1`) — patch 20, current

**Single source of truth.** `v1(doses, halfLifeHours, sampleDate)` is called by both the Current Level dashboard card (`zge`) and the dose-chart series builder (`Vge`). Any change to level math is one replacement of this string.

### Exact shipped code (minified, as inserted by `glpal_patch20_bateman.py`)

```js
__glpalTmax=t=>({168:48,127:24,120:24,108:48,13:11})[t]||Math.min(48,Math.max(6,.2*t)),
__glpalKa=(()=>{const c={};return(k,m)=>{const y=k+"|"+m;if(c[y])return c[y];
  let l=k*1.000001,h=k*1e3;for(let j=0;j<80;j++){const x=(l+h)/2;
  Math.log(x/k)/(x-k)>m?l=x:h=x}return c[y]=(l+h)/2}})(),
v1=(r,t,e)=>{const T=t>0?t:168,K=Math.LN2/T,
  m=Math.min(__glpalTmax(T),.95/K),A=__glpalKa(K,m),
  F=O=>O<0?0:A/(A-K)*(Math.exp(-K*O)-Math.exp(-A*O)),pk=F(m);
  return r.reduce((n,i)=>n+i.dose*F((e.getTime()-i.date.getTime())/36e5)/pk,0)}
```

### Math

One-compartment, first-order absorption and elimination (Bateman function), peak-normalised.

- `T` = half-life in hours (falls back to 168 if falsy/≤0)
- `ke = ln2 / T`
- `Tmax` = lookup by stored half-life: 168→48, 127→24, 120→24, 108→48, 13→11; else `clamp(0.2·T, 6, 48)`; then `min(Tmax, 0.95/ke)` (Bateman peak cannot exceed 1/ke)
- `ka` solved so that the curve peaks at Tmax: the analytic peak time is `ln(ka/ke)/(ka−ke)`; bisection on `[ke·1.000001, ke·1000]` for 80 iterations, memoised on `(ke, Tmax)`
- `f(o) = ka/(ka−ke) · (e^(−ke·o) − e^(−ka·o))` for `o ≥ 0` hours since dose; 0 before the dose
- contribution of a dose = `dose · f(o) / f(Tmax)` → a 1 mg dose peaks at exactly 1 mg ("mg on board" convention preserved)
- total = sum over all doses of that medication

Long tail: as `e^(−ka·o)` vanishes the curve is pure half-life decay, so week-scale behaviour matches the old model.

### Reference reimplementation (Python, from `tests/test_samplenow.py`)

```python
def level(doses, half_life, hours_since_each):
    t = half_life if half_life > 0 else 168.0
    ke = math.log(2) / t
    tmax = {168: 48, 127: 24, 120: 24, 108: 48, 13: 11}.get(t, min(48.0, max(6.0, 0.2 * t)))
    tmax = min(tmax, 0.95 / ke)
    lo, hi = ke * 1.000001, ke * 1e3
    for _ in range(80):
        x = (lo + hi) / 2
        if math.log(x / ke) / (x - ke) > tmax: lo = x
        else: hi = x
    ka = (lo + hi) / 2
    f = lambda o: 0.0 if o < 0 else ka / (ka - ke) * (math.exp(-ke * o) - math.exp(-ka * o))
    pk = f(tmax)
    return sum(d * f(o) / pk for d, o in zip(doses, hours_since_each))
```

### Previous model (patches ≤19, for reference)

```js
v1=(r,t,e)=>r.reduce((n,i)=>{const o=(e.getTime()-i.date.getTime())/36e5;
  if(o<0)return n;let s;if(o<24){s=i.dose*(o/24)}
  else{s=i.dose*Math.exp(-.693*(o-24)/t)}return n+s},0)
```
Linear 24 h ramp, then exponential decay. Kink at hour 24; overstated decline on days 1–3 for Tmax≈48 h drugs.

### Inputs to `v1` — sourcing rules (unchanged by any patch)

- **Half-life per medication** = `halfLifeHours` of the **earliest** dose record with that exact medication name (first-record-wins). Card call site additionally has `|| 168`.
- **Dose date** = `parseLocalDate(record.date)` = local midnight. The `time` field is **ignored**.
- **Sample time:** Current Level card = `new Date()` (now). Dose chart = local midnight for each day in `[firstDate, lastDate]`, except today, which is sampled at now (patch 14). Future days extend into a dotted "Combined_future" series.
- Chart series construction (`Vge`): walk days; `O = axis.indexOf(day)`; `O <= todayIdx → past series x`, `O >= todayIdx → future series b`; today's point is in both. Last element of `x` = current level → patch-13 marker.

## 2. Date handling (patch 7)

Stored dates are `YYYY-MM-DD` strings. Rule: **parse-for-display must be local**, **parse-for-storage round-trips stay UTC**.

```js
function __glpalLocalDate(v){
  if(typeof v=="string"){const m=/^(\d{4})-(\d{2})-(\d{2})$/.exec(v);
    if(m)return new Date(+m[1],+m[2]-1,+m[3])}
  return new Date(v)}
```
Applied by regex to single-argument `new Date(x).toLocaleDateString` sites (the 3-argument `new Date(y,m-1,d)` form is already correct and excluded) plus one two-step site. Sites doing `new Date(s).setTime(...)→toISOString().split("T")[0]` are UTC-in/UTC-out and correct; the patcher asserts none of them were touched.

## 3. Weight chart bounds (patch 11) and period window (patch 12)

```
pad  = (maxW - minW) * 0.1 || 5           // kge, pre-existing
yMin = floor(min(minW, goal) - pad)
yMax = ceil (max(maxW, goal) + pad)       // projection excluded
```
```js
function __glpalWeightZoom(k,O,e){          // k = category axis, O = index of today, e = period
  const n=k&&k.length?k.length:0;
  if(n<2)return{start:0,end:100};
  const D={week:14,month:30,"90days":90}[e];
  if(!D)return{start:0,end:100};             // "all"
  const t=O>=0&&O<n?O:n-1,
        s=Math.max(0,t-D+1),
        x=Math.min(n-1,t+Math.ceil(D*.5));   // half-window lookahead, as the dose chart does
  return{start:s/(n-1)*100,end:x/(n-1)*100}}
```
Also adds `a` (period) to the chart-option memo's dependency array — the memo never listed it, so with short histories it never re-ran and showed a stale period. The dose chart's own `dataZoom` is asserted untouched.

## 4. Recolour (build stage)

`make_palette.py` maps every purple in the UI to a muted orange (target hue from `#F58C1D`, H≈31°, saturation damped) while **preserving WCAG relative luminance**, so all contrast ratios are unchanged. `recolour.py` applies `palette.json` to the bundle and CSS in every form: `#RRGGBB` any case, `rgb()/rgba()` triplets, Tailwind arbitrary values like `from-[#B19CD9]`. Accent `#B19CD9 → #D69A5A`.

## 5. Service worker

Generated per build. Cache name embeds a 12-hex fingerprint of the SHA-256s of every shipped file, so any rebuild invalidates the old cache. Install: `addAll` with `cache:'reload'` then `skipWaiting`. Activate: delete other caches, `clients.claim`. Fetch: GET + same-origin only; navigations network-first with cached `index.html` fallback; assets cache-first with network fill. Never touches IndexedDB.

## 6. Icons

`make_icons.py`: "T" monogram in accent on `#1A1815`, kept inside the maskable safe zone; outputs 512/192 PNG + ICO into `build/brand/`.

## Adding a change — the rule

**Never hand-edit `docs/assets/app/index-DwosoAbB.js`.** Every change is a new patch:

1. Locate the target in the **patch-19/20 artifact** (or `docs/…js`, but remember docs/ is post-recolour: anchor colours must be the original purple `#B19CD9`, and any colour literal in an anchor must match the pre-recolour bundle). The convenient way: run the build once, then grep `build/.artifacts/titrate-index-bateman.js`.
2. Create `build/glpal_patchNN_<name>.py` following the existing template:
   - module docstring: **Symptom / Cause / Fix / what deliberately does not change / Usage**
   - `EXPECTED_INPUT_SHA256` = previous stage's output hash
   - `OLD`/`NEW` literal strings (or anchor + regex); assert `text.count(OLD) == 1` (or the exact expected count); assert new helper names are absent from the input
   - assert anything that must stay untouched (e.g. patch 14 asserts `v1` unchanged; patch 12 asserts the dose chart zoom unchanged)
   - compute the output, print its SHA, then pin `EXPECTED_OUTPUT_SHA256` and re-run
   - generate long literals from the artifact (patches 18/19 did) rather than retyping minified code
3. Wire into `build_fork.py`: new `EXPECTED_<X>_SHA`, new block in `patch()`, update `SHIP_SHA`.
4. Run the build; `node --check` the shipped bundle if available.
5. Add/extend a test in `tests/` (see below). Keep seeds relative to `date.today()`.
6. Commit: patch script + `build_fork.py` + regenerated `docs/` (bundle and `sw.js` change every build; other docs files only when the shell changes). Commit message = one line stating the user-visible effect, e.g. "fix the weight chart period selector".
7. Push to `main`; GitHub Pages redeploys from `docs/`. The SW cache fingerprint changes, so installed PWAs pick up the new version on next launch/reload.

Minified identifiers are stable for this upstream SHA only. Useful ones: `v1` level model; `zge` Current Level card; `Vge` dose-chart series builder; `Ege` dose-array mapping; `Hge` Performance Overview (now just Time Active); `kge` weight stats helper; `Oge` old weight zoom helper; `xz` goal-weight picker; `$U` settings modal; `Oo` kg→lb; `fw` cm→ft/in; `pz` ×2.20462; `gz` lb→kg; `st` Dexie db instance; `xW` deleteDose; `__glpalUpdateDose`, `__glpalLocalDate`, `__glpalWeightZoom`, `__glpalTmax`, `__glpalKa` are ours.
